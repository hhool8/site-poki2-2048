# Prompt: Generate New 2048 Variant Page

Create a complete HTML page for a new 2048 variant under this project.

## Inputs

- Variant name:
- Slug:
- Primary keyword:
- Secondary keywords (3-5):
- Game embed URL:
- Control keys:

## Required Output

- Full HTML page based on `templates/variant-page.template.html`.
- Unique `title`, `meta description`, `H1`, and intro paragraph.
- 200-300 words original copy with:
  - How to play
  - Why this variant is different
  - 3 practical strategy tips
- Internal links to:
  - Homepage (`/`)
  - Two related variant pages
- Self-referencing canonical URL.
- Valid JSON-LD block using real, known fields only.

## Constraints

- Do not copy text from vendor pages.
- Do not include fake ratings or made-up review count.
- Keep paragraphs short and readable on mobile.
