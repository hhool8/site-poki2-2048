# Prompt: Metadata and Technical SEO Audit

Audit this page for metadata and technical SEO quality.

## Inputs

- File path:
- URL:
- Primary keyword:

## Audit Checklist

- Title length: 50-65 chars and keyword near start.
- Meta description: 140-160 chars with clear user value.
- Single H1 and logical H2/H3 structure.
- Canonical is absolute and self-referencing.
- Open Graph tags present and image is valid.
- JSON-LD is valid and contains no fabricated ratings.
- Internal links: at least 3 and all resolve.
- Mobile viewport and no horizontal scroll.

## Output Format

- Pass/Fail table with concise fixes.
- Revised title and description if current fails.
