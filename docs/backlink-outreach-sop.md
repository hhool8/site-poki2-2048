# Backlink and Outreach SOP

## Goal

Acquire relevant, low-risk links that support long-tail rankings for 2048 variant pages.

## Approved Channels

- Community Q&A posts (helpful answers only).
- Niche puzzle game forum threads.
- Curated browser game list submissions.

## Anchor Text Rotation

- Brand + topic: `Poki2 2048 collection`
- Neutral: `play here`
- Partial match: `2048 cupcakes page`
- Avoid repeating exact-match anchor excessively.

## Outreach Template

1. Explain user problem solved by your page.
2. Share one practical tip from your guide.
3. Add one supporting link to the most relevant page only.

## Risk Controls

- No automated link blasts.
- No irrelevant directory spam.
- Keep domain identity clear as an independent collection hub.
