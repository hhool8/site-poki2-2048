# Weekly Operations SOP

## Monday: Data Pull

- Export last 7 days query and page report from GSC.
- Mark pages by bucket:
  - Bucket A: position 1-10
  - Bucket B: position 11-20
  - Bucket C: position > 20

## Tuesday: Metadata Iteration

- For Bucket B pages, test one title update and one description update.
- Keep keyword near title start and keep user value explicit.

## Wednesday: Content Refresh

- Add 80-120 words of new insights to one page.
- Refresh FAQ with one new question from GSC query patterns.

## Thursday: Internal Linking

- Add 2-3 context links from strongest page to weakest page.
- Rotate anchor text naturally.

## Friday: Technical QA

- Validate canonical tags.
- Validate schema JSON-LD formatting.
- Check mobile rendering for all key pages.

## KPI Targets

- CTR: +0.3% week-over-week on updated pages.
- Average position: improve at least 1 position for optimized pages over 2-3 weeks.
- Bounce proxy: increase average engaged sessions from page transitions.
