# Google Search Console Checklist

## Property Setup

- Add domain property for `poki2.online` (already stable).
- Add URL-prefix property for `https://2048.poki2.online/`.

## Initial Submission

- Submit `https://2048.poki2.online/sitemap.xml`.
- Use URL Inspection for:
  - homepage
  - a representative generated game page
- Request indexing for each.

## First 14 Days Monitoring

- Track Coverage issues daily.
- Track mobile usability errors daily.
- Track Core Web Vitals warnings.
- Track queries and average position for:
  - 2048 unblocked
  - 2048 variant games
  - 2048 strategy tips

## Optimization Loop

- If impressions increase but CTR falls, rewrite title and description.
- If position stays > 15, expand section depth and add internal links.
- If a page starts ranking, refresh date and improve FAQ clarity.
